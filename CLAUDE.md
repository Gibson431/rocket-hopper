# Rocket Hopper Simulator

Python 6-DOF simulator for developing a TVC rocket-hopper flight controller.

**Before doing anything, read [docs/AGENT_START.md](docs/AGENT_START.md).** It explains how to
find the next step, how the plan is organised, and how to record progress.

- Development method: test-first, per [skills/test-driven-developer/SKILL.md](skills/test-driven-developer/SKILL.md) (read it before writing code)
- Every step needs a `PASS` from an independent reviewer subagent before it is marked done: [docs/REVIEW.md](docs/REVIEW.md)
- Plan overview: [docs/PLAN.md](docs/PLAN.md)
- Shared conventions (frames, units, state layout, interfaces): [docs/CONVENTIONS.md](docs/CONVENTIONS.md)
- Progress tracker (source of truth for what is done): [docs/PROGRESS.md](docs/PROGRESS.md)
- Per-step instructions: [docs/steps/](docs/steps/)
